# 4-Cylinder Internal Combustion Engine Assembly

## Project Overview
A complete 3D mechanical assembly of a 4-cylinder internal combustion engine designed in Autodesk Inventor. The model features a synchronized crankshaft, connecting rods, and piston mechanisms with precise mechanical constraints to simulate realistic engine kinematics.

![Engine Render](4%20cylinder%20engine%20assembly.png)

## Technical Details
* **Software:** Autodesk Inventor Professional
* **Key Features:**
  * Kinematic synchronization of the crankshaft and pistons.
  * High-fidelity 3D modeling of the engine block and internal components.
  * Exported as `.STEP` for universal CAD compatibility and `.STL` for native GitHub 3D web viewing.
* **Author:** Michael Muchemi | Aerospace Engineering

## How to View
* **In Browser:** Click on the `.stl` file in the file list above to rotate and inspect the 3D model directly in GitHub's interactive 3D viewer.
* **In CAD Software:** Download the `.step` file to open the full assembly in SolidWorks, Fusion 360, AutoCAD, or Inventor.
